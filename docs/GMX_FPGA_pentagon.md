# Схема FPGA GMX "PentaGON" (схема 4)

Исходные файлы: [../fpga/pentagon/](../fpga/pentagon/). Структура и способ записи те же, что у схемы [Scorpion](GMX_FPGA_scorpion.md). Кристалл EPF8452ALC84, 254 ячейки, 68 выводов. Блок схемы во Flash: 0x8000, дата 22.01.99, параметр порта `xx00` = `E0` (ST/PENT, BLKEX2, BLKEXT), параметр `#7EFD` = `10` (банк ПЗУ 1).

## Модули

| модуль | экземпляр | назначение |
|---|---|---|
| `clocks` | u_clk | 7 МГц, такт Z80 (турбо/норма), фаза RAS/столбца, кнопка турбо, такт пикселей |
| `cpu_io` | u_cpu | дешифрация портов, строб записи по началу и по концу цикла, чтение портов на DB, WR на материнскую плату |
| `ports` | u_ports | `#7FFD` (вариант Pentagon), бордюр `#FE`, `#DFFD`, `#7EFD`, `#78FD`, `xx00` |
| `magic` | u_magic | Magic, теневое ПЗУ и TR-DOS (выборка из 3Dxx), защёлки конфигурации |
| `memctl` | u_mem | страницы, мультиплексор MA, RAS/CAS/WE, защёлки DD5/DD9, WAIT |
| `video_timing` | u_vt | счётчики точек и строк (кадр 320 строк), синхроимпульсы, INT, FLASH |
| `video_out` | u_vo | регистр пикселей, атрибуты, бордюр, RGBI |

Модуль `gfx640` отсутствует: в схеме нет регистров скроллинга и счётчика видеоадреса режима 640x200.

## Отличия от схемы Scorpion

- Параметр `CBR` модуля `memctl` такой же, как в схеме Scorpion: регенерация DRAM циклами CAS-before-RAS в видеослотах бордюра и гашения (`refr = vid_slot & bord`), в турбо - в слоте бордюра с h4..h1 = 1111, условие ожидания `wait_cond` учитывает этот слот.
- `#7FFD`:
  - при BLKEX2 = 1 порт декодируется только по A1 = 0, A15 = 0;
  - бит D5 (`blkpk1`) только устанавливается (`blkpk1.ena = DB5 & !wr7ffd_n; blkpk1.d = VCC`) и сбрасывается при RESET; при `blkpk1` = 1 запись в `#7FFD` заблокирована.
- Бордюр `#FE` декодируется по A0 = 0.
- Бордюр и бит SCR записываются по началу цикла записи (`iowr_go_n`, триггер от `io_wr` по 7 МГц), остальные регистры - по концу (`port_wr_clk`).
- Порт `#1FFD` (BLK1, TRDOS, SYS3) и регистры скроллинга отсутствуют. На месте их битов при чтении конфигурации выдаётся 0 (`ml_zero`).
- Порты `#7EFD` (MagEnable, Graphic), `#78FD`, `#DFFD` и `xx00` присутствуют и отключаются битом BLKEXT. При BLKEXT = 1 схема работает как Pentagon 128. Включение портов: [GMX_findings.md](GMX_findings.md), раздел 2.
- Кадр 320 строк, INT по началу кадрового синхроимпульса при ST/PENT = 1. На время строчного синхроимпульса выход RGBI гасится (`blank_n`).
