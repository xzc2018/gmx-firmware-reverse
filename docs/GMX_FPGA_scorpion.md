# Схема FPGA GMX "Scorpion" (схемы 1, 2, 5, 6, 7)

Исходные файлы: [../fpga/scorpion/](../fpga/scorpion/). Верхний уровень `scorpion.tdf`, 8 модулей `*.tdf` с прототипами `*.inc`, назначение выводов и ячеек и параметры компиляции в `scorpion.acf`. Кристалл EPF8452ALC84, 328 ячеек, 68 выводов. Назначение выводов: [fpga_pins.csv](fpga_pins.csv).

Схемы 1 (Start Sch), 2 (Work Sch), 5 (Komposit), 6 (DK_test) и 7 (Scheme 7) содержат один и тот же битстрим и различаются только параметрами портов `xx00` и `#7EFD` в блоке схемы.

## Запись в исходных файлах

- Сигналы объединены в векторы (`h[8..0]`, `v[7..0]`, `sys[3..0]`, `sw[6..0]`, `ga[13..0]`, `px[7..0]`, `ma_out[9..0]`); на верхнем уровне - шины `A[15..0]`, `DB[7..0]`, `MA[9..0]`, `MD[7..0]`.
- Регистры портов записаны как `DFFE` (`sm[].ena = !wrdffd_n; sm[].d = DB[2..0];`), мультиплексоры - как `IF ... THEN ... ELSE`, разряды счётчиков - как `h5.d = h5 $ (hc3 & h4)`, сдвиговый регистр - как `px[].d = (px[6..0], GND)`. Остальная логика записана уравнениями.
- Компилятор выдаёт 71 предупреждение о неиспользуемых разрядах векторов, которые передаются в модули целиком.

## Работа схемы

### Процессор и порты

- Сигнал WR на FLEX не подаётся. Запись в порт определяется как цикл IORQ без RD (`io_wr`). Строб `port_wr_clk` формируется задержкой `io_wr` по такту Z80; число ступеней задержки зависит от режима турбо.
- Дешифрация:
  - `#7EFD`, `#7AFD`, `#78FD`, `#7CFD` различаются по A10, A9 при A15 = 0, A14 = 1, A8 = 0;
  - `#7FFD`: A14 = 1, A8 = 1; при BLKEXT порт отличается от `#7xFD` только по A15;
  - `#1FFD`: A14 = 0, A8 = 1;
  - `#DFFD`: A15 = 1, A13 = 0;
  - `xx00`: A0 = A1 = A5 = 0 с учётом теневого режима (см. ниже);
  - BLKEXT и BLKEX2 отключают расширенные порты.
- Блокировка `#7FFD` битом BLKPK1 не действует при `#7EFD.D2` = 1.
- Чтение конфигурации:
  - `#7AFD`: SYS0..3, SM0..2, BRD0;
  - `#7EFD`: BLKPK1, SCR, турбо, Graphic, ST_PENT, BLKEXT, BLK1, BRD2;
  - `#78FD`: SW0..6, BRD1;
  - `#FF`: байт `MD`, защёлкнутый по h2.
- Защёлки конфигурации (`ml_*`) фиксируются при нажатии Magic (`magic_hold`) и освобождаются чтением `#FF`.
- `WROUT/` (WR на материнскую плату) формируется из того же строба, кроме записи в порты GMX.
- BLKEXT и BLKEX2 сбрасываются при RESET только при FIXROM = 0 (`ext_rst = RESET # fixrom`).

### Теневое ПЗУ и TR-DOS

- Выборка команды (M1) из 3D00-3DFF при включённом ПЗУ 48 асинхронно устанавливает флаг `dos_act`.
- Выборка команды из ОЗУ (`m1_ram`) перезаписывает флаг; ПЗУ TR-DOS отключается.
- Magic также включает теневой режим (`magic_act` -> `dos_act`).
- В теневом режиме порты `#FE`, `#FF`, `xx00` декодируются с учётом `dos_act xnor trdos` (`sel_ula`, `sel00_n`).

### Турбо

- `turbo_req` переключается кнопкой TRBB, которая опрашивается по INT, и асинхронно загружается записью в `#7EFD.D7`.
- `turbo` - синхронная копия `turbo_req`, меняется вне цикла IORQ.
- `CLKCPU = turbo ? 7 МГц : !RAS` (3,5 МГц). Сигнал `WAIT/` формируется только в режиме турбо.

### Память

- Номер страницы окна: `01` - банк 5, `10` - `#78FD` (SW1 инвертирован, после сброса банк 2), `11` - `#7FFD`/`#1FFD`/`#DFFD`.
- Биты 4 и 5 номера страницы и выбор SIMM (SM2/SW6) мультиплексируются по фазе строки/столбца на MA9 и CAS0/CAS1.
- Видеоадрес на MA формируется из счётчиков h/v (экран ZX) или `ga0..ga13` (экран 640x200) по биту `graphic`.
- Чтение процессором выполняется через защёлку DD9 (такт `WRBUF`, выход `RAM/`), второй SIMM - через защёлку DD5 (такт `CAS1`, выход `EBUF`).
- Регенерация DRAM выполняется циклами видеочтения: строка на MA0..MA8 от счётчиков h/v, MA9 постоянен (512 строк). В режиме турбо видеочтения выполняются только в активной области.
- Параметр `CBR` (по умолчанию 0, модуль `memctl`): при CBR = 1 видеослоты бордюра и гашения выполняются как циклы CAS-before-RAS (`refr = !cpu_slot & bord`; CAS0/ и CAS1 активны весь слот), в турбо на бордюре процессору не отдаётся слот с h4..h1 = 1111 (`steal_n`). Описание: [../README.md](../README.md), раздел "Регенерация DRAM".

### Видео

- Счётчик точек тактируется 7 МГц, счётчик строк - сигналом `line_clk`. Длительность кадра (312 или 320 строк) и момент INT (конец или начало кадрового синхроимпульса) задаются битом ST_PENT порта `xx00`.
- Цвета: выводы FLEX G (1), R (3), B (84) выдают биты атрибута 0, 1, 2. В палитре ZX Spectrum это синий, красный, зелёный.
- Режим 640x200:
  - такт пикселей 14 МГц;
  - счётчик `ga0..ga13` считает байты;
  - по кадровому импульсу или концу экрана разряды 4..13 асинхронно загружаются из `#7AFD.D4..7` и `#7CFD.D0..5`, разряды 0..3 сбрасываются; шаг скроллинга - одна строка.

## Файл scorpion.acf

- Выводы DATA0 (14) и SDOUT (78) освобождены (`UNRESERVED`): на них выведены DB0 и RDR/.
- Включён `ENABLE_DCLK_OUTPUT`.
- Назначения ячеек иерархические, в кавычках: `"|ports:u_ports|sys0" : LOCATION = LC2_A18;`.
